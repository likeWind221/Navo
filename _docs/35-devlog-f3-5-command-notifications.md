# F3.5 命令入口与通知展示

## 做了什么

- 输入框候选先识别斜杠命令；合法命令通过桌面命令桥接提交，普通文本继续走 Agent 回合。
- 会话状态新增命令消息与时间线，命令事件按 `commandId` 原位更新为执行中、成功、失败或取消，并在命令错误时生成系统提示行。
- 对命令通知增加独立样式和状态可访问名称；保留没有时间线数据时的旧消息列表兼容路径。

## 关键决策

- 只允许小写字母开头、由小写字母/数字/连字符组成的命令名；格式错误在 Renderer 本地反馈，不发送到后端。
- 命令和活动回合使用独立活动标识与取消入口；命令通知只在首次见到 `commandId` 时加入时间线，后续事件更新同一条记录。

## 坑与发现

- 命令桥接可能先返回接受结果、再异步发送 `command-started`；Reducer 必须去重，避免重复系统提示行。
- 旧版消息仍只有聚合 `text`，列表组件需要同时支持旧消息与新的内容块/时间线状态。
