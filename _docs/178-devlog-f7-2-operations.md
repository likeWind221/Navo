# F7.2 资料导入与整理

## 做了什么

- 资料库新增项目级操作状态所有者：导入流、文件夹创建 / 移动 / 删除、资料编辑 / 移动 / 替换 / 删除共享同一操作进度模型。
- 导入支持多文件与目录选择，逐项展示已保存 / 失败 / 取消及正文状态；流错误、完成、取消都有明确终态，操作中的项目关闭会取消活动订阅并清理。
- 文件夹支持新建、移动、非空目录先检查再递归确认删除；资料支持编辑名称 / 描述、移动位置、替换和删除，版本冲突保留当前草稿并展示最新事实。
- 编辑、移动、删除和确认改用原生 `showModal()` 页面弹窗；背景不可点击、Tab 留在当前层、Escape 只关闭最上层并恢复触发按钮焦点。
- 明确导入落点：文件进入资料库根目录，目录按内部相对路径导入，导入后可移动；不把“直接导入当前文件夹”写成已有能力。
- 操作列表限制最近四项，逐项结果与取消入口可读；资料和文件夹选择互斥，导航后清除旧目录选择。

## 关键决策

- 操作状态提升到 `ProjectWorkspace`，资料库关闭不丢失进行中的导入或整理；项目切换或关闭时统一取消并清理，不把生命周期交给单个面板。
- 早到事件按 subscription 暂存，导入回执到达后只取回属于本订阅的事件；并发导入不会互相清空待处理队列。
- 终态不可被后续迟到事件复活；部分成功由逐项失败 / 取消推导，不把部分成功写成整体失败。
- 编辑表单保存打开时的 `resourceId + expectedRevision + 原始字段`，外部更新后提交得到版本冲突，草稿保留；不自动覆盖外部修改。
- 操作按钮的可见性与可用性按操作类型区分；不能取消的短操作不展示取消入口，避免制造无效控制。

## 坑与发现

- F7.1 的资料库订阅监听数从 1 变为 2：操作事件监听是新增的独立生命周期，回归脚本已同步并重新通过。
- 文件夹与资料同时选中会让移动 / 删除弹窗指向错误目标；现在选择资料会清除文件夹选择，选择文件夹会清除资料选择，路径变化也会清除旧选择。
- 并发导入若在首个回执时清空全部 pending 事件，会丢掉另一导入的逐项结果；改为按 subscription 删除。
- 操作列表只在最新操作身份或状态变化时滚动，新增逐项结果不会触发；已把 items 数量加入滚动依赖。
