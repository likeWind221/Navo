# F3.8 消息列对齐修正

## 做了什么

- 滚动区改为在左右两侧对称预留稳定滚动条槽位，使消息列与下方输入框使用相同水平中心。
- F3.6 Electron QA 增加 Assistant 与 Composer 左边界几何断言，并重新生成验收结果与截图。

## 关键决策

- 修正滚动容器的布局坐标系，不给单个 Assistant 消息添加补偿边距；用户消息和系统提示因此继续共享同一消息列。
- 保留稳定滚动条槽位，避免内容高度跨过滚动阈值时发生水平跳动。

## 坑与发现

- `scrollbar-gutter: stable` 只在右侧预留槽位，消息列在缩窄后的滚动区域中居中，输入框却在完整区域中居中，因此两者相差半个滚动条宽度。
- 修正后 Electron 实测 Assistant 与 Composer 左边界均为 257.5px。

## 下一步

- 当前无后续实现依赖；用户可在常用窗口尺寸下继续进行视觉复验。
