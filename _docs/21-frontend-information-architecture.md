# SkillWorld 前端信息架构

## 1. 目标与边界

本信息架构描述桌面端如何呈现“总体目标 → 学习路线 → 能力 Node → 教材/练习/对话”，作为后续静态界面和跨进程契约的依据。

当前只确定页面关系、职责和交互语义，不选择 Router、状态管理、组件库或 IPC/RPC 方案；尚未实现的 Main Agent、DAG、Grader 与 Verification 只保留入口位置，不伪装为可用功能。

## 2. 顶层结构

```text
AppShell（应用外壳）
├─ GoalHome（目标首页）
├─ GoalWorkspace（目标工作区，规划能力）
│  ├─ RoadmapView（学习路线视图）
│  └─ MainConversation（主协调对话）
├─ NodeWorkspace（节点学习工作区，首个可见功能）
│  ├─ MaterialPanel（教材面板）
│  ├─ PracticePanel（练习面板）
│  └─ NodeConversation（节点统一对话）
└─ Settings（设置）
```

`AppShell` 提供窗口级导航和当前上下文，不保存领域事实。领域内容与会话历史以后端快照为准，前端状态只负责展示、编辑草稿和请求状态。

## 3. 页面清单

页面路径是信息架构标识，不代表已经选定路由库。

| 页面 | 概念路径 | 当前可用性 | 页面职责 | 明确不做 |
|---|---|---|---|---|
| 目标首页 | `/` | 规划中 | 创建、恢复和浏览学习目标，显示最近访问入口 | 不在本地推断目标状态 |
| 目标工作区 | `/goals/:goalId` | 后续阶段 | 展示目标、DAG/Road Map、全局进展与 MainSession | 不读取完整 NodeSession，不替 Main Agent 修改图 |
| Node 学习工作区 | `/goals/:goalId/nodes/:nodeId` | 首个实现目标 | 围绕一个 Node 展示教材、练习和统一 NodeSession 对话 | 不展示隐藏参考答案，不允许跨 Node 写入 |
| 设置 | `/settings` | 规划中 | 管理外观、可访问性及未来 Provider/连接配置 | 不直接承载学习内容或 Agent 对话 |

在 Main Agent 与 DAG 尚未实现时，目标首页和目标工作区只能作为静态信息架构或明确标注“尚未接入”的入口；不能用前端假数据制造真实规划已完成的错觉。

## 4. 导航模型

### 4.1 全局导航

左侧一级导航保持稳定，只包含：

1. `目标`：返回目标首页；
2. `当前学习`：有最近 Node 时恢复该 Node 工作区，无记录时回到目标首页；
3. `设置`：进入应用级配置。

一级导航不直接列出所有 Node，避免目标增多后无限膨胀。

### 4.2 上下文导航

目标与 Node 的层级通过面包屑表达：

```text
目标名称 / 路线 / Node 名称
```

- 点击目标名称返回目标工作区；
- 点击路线返回目标工作区中的路线区域；
- 当前 Node 不可点击；
- 从一个 Node 切换到另一个 Node 时必须整体切换 Node 快照和 NodeSession，不保留上一个 Node 的草稿。

### 4.3 返回与恢复

- 应用重启优先恢复最后一个合法页面；目标或 Node 已不存在时回退目标首页并说明原因；
- 浏览器式前进/后退只改变视图位置，不撤销领域事实；
- 进行中的 Turn 离开页面前应提示，取消只影响当前 Turn，不删除既有对话和内容。

## 5. Node 学习工作区

### 5.1 桌面布局

```text
┌──────────────── AppHeader（应用标题栏）───────────────┐
├─ ContextHeader（Node 目标与上下文）──────────────────┤
│ ┌──────── ContentArea（内容区）──────┐ ┌─ ChatPanel（对话区）─┐ │
│ │ MaterialPanel（教材面板）          │ │ NodeConversation     │ │
│ │ PracticePanel（练习面板）          │ │ （统一 NodeSession）  │ │
│ └────────────────────────────────────┘ └──────────────────────┘ │
└───────────────────────────────────────────────────────────────┘
```

宽屏下内容区与对话区并列，教材和练习通过同一内容区内的分页或可调整分栏呈现；窄屏下降级为“教材 / 练习 / 对话”三个可切换区域。响应式变化不能创建额外 Session，也不能让用户误以为教材和练习属于两个 Agent。

### 5.2 ContextHeader

展示 Node 名称、能力目标、所属目标和连接/运行状态。除非存在 Verification 事实，否则不显示“已掌握”；内容已生成、Turn 已完成也不能替代 mastery。

### 5.3 MaterialPanel

展示最新教材 revision、正文和来源列表。空态引导用户通过统一对话生成教材；来源链接交给 Electron 安全打开，不允许页面直接获得系统权限。

### 5.4 PracticePanel

展示最新题集 revision、题目和未来的作答入口。学习者视图永不展示隐藏参考答案；F1 静态阶段不实现提交、批改或 mastery 状态。

### 5.5 NodeConversation

展示同一 NodeSession 的连续历史，承担生成、答疑以及修改教材或题目的自然语言入口。领域面板只接受后端结构化内容快照更新，不解析 assistant 文本来猜测教材或题集是否变化。

## 6. 状态与反馈

每个可加载区域统一区分：

- `loading`：首次读取且尚无可展示快照；
- `ready`：显示最后确认的快照；
- `empty`：读取成功但内容尚未生成；
- `refreshing`：保留旧快照并提示后台更新；
- `error`：保留可用旧内容，提供重试和可理解的错误信息；
- `offline`：桌面端无法连接后端能力，不把请求显示为成功。

对话额外区分 `queued`、`running`、`cancelled` 和 `failed`。取消或失败只终止当前 Turn；已提交的消息、教材和题集快照继续显示，前端不得乐观伪造领域提交成功。

## 7. 数据与权限边界

| 前端区域 | 允许读取 | 允许发起 | 禁止行为 |
|---|---|---|---|
| 目标工作区 | 目标摘要、图投影、MainSession 投影 | 全局协调请求 | 写 NodeSession、宣布 mastery |
| 教材面板 | 当前学习者教材快照、公开来源 | 请求 NodeAgent 修改 | 解析对话生成事实、跨 Node 写入 |
| 练习面板 | 学习者题集视图 | 请求生成/修改、未来提交答案 | 读取隐藏参考答案 |
| Node 对话 | 当前 NodeSession 投影 | start/send/stop | 读取其他 NodeSession |
| 设置 | 可公开配置和连接状态 | 更新允许的配置 | 获取密钥明文、直接访问 Provider SDK |

Renderer 不导入后端 `src/**`，也不持有 Cordis Service、Store 或文件系统能力。未来所有跨边界操作必须通过 preload 暴露的窄接口，并返回可运行时校验的数据。

## 8. 基础可访问性要求

- 一级导航、面包屑、内容区和对话区使用明确 landmark 与标题层级；
- 教材/练习切换可由键盘完成，并具备可见焦点；
- 状态不能只依赖颜色，运行、失败和取消都提供文字；
- 新消息和内容 revision 更新使用非打断式提示，不强制抢夺输入焦点；
- 窄屏切换区域后保留合理焦点位置和未发送草稿。

## 9. 后续实现顺序

F1.2 只实现 `NodeWorkspace` 的静态布局与上述状态样例。目标首页、目标工作区、真实导航、数据加载、消息发送和 IPC/RPC 均等待各自后续 Step，不在静态工作区中提前实现。
