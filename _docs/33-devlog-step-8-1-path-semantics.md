# 8.1 文件工具路径语义修订记录

## 做了什么

- 将 `FilePath` 从“仅 Session 相对路径”修订为执行世界路径：相对路径以 Session `cwd` 为基准，绝对路径保留执行世界语义。
- 同步 `read`、`find`、`write`、`edit` 的模型 Schema 描述和路径错误文案。
- 新增协议测试，验证相对/绝对路径可通过 Schema，模型不能传入 `sessionId` 或工作区根。

## 关键决策

- 对齐 DSH 的 `SessionHeader.cwd` 与执行世界模型；不按 `sessionId` 自动生成物理子目录。
- 8.1 只定义输入和错误契约，不解析真实文件目标、不执行 IO，也不把路径契约当作沙箱。
- 保留 22 号记录作为初版历史记录；新的路径语义以后续 8.1 修订和 8.2 实现为准。

## 坑与发现

- 当前 `ToolService` Schema 校验只能确认字段类型和结构，不能完成 `cwd` 解析、符号链接和执行世界授权；这些边界属于 8.2。
- `path-not-allowed` 错误类型保留给后续执行世界或 Provider 策略，不再在模型文案中暗示“必须是相对路径”。

## 下一步

8.2.1 已完成 Session `cwd` 下的路径解析和稳定文件目标；下一步进入 8.2.2，实现有界文本读取与目录发现。
