# BUG-047：Main 对话刷新后不显示

## 现象与复现

2026-11-17 用户报告前端自动刷新或应用重启后，Main 对话区域为空。尚未对用户现场执行历史读取或复现。

## 已证实事实与根因假设

`ProjectTurns` 的对话保存在前端内存；`ProjectConversation` 只从该状态渲染，不读取已有 Session 历史。刷新会重建前端状态。项目详情提供 Main Session ID，桌面已有 `session.history.v1` Bridge，但当前项目页面尚未消费它。该接口返回有效历史，并非完整原始回合档案。现场历史是否仍存在以及可读取尚未核验。

## 修复内容

前端通过现有 Session Bridge 按页读取 Main 的有效历史，显示正文、思考、工具调用与结果以及摘要检查点；读取完成前暂不发送新消息，切换视图后复用本次运行首次读取的历史，避免与当前运行的新消息重复。读取失败时显示重试，历史版本变化时从第一页重新读取。Node 历史和完整原始档案不在本次范围。

## 验证结果与边界

Windows 本机执行前端 typecheck、完整测试（34 文件、202 项）和 build 均通过；定向测试覆盖跨页加载、切换时复用以及历史变化后重试。未读取用户现场会话、未完成真实桌面刷新／重启复验，也未验证中断回合和不可读会话的恢复状态；Node 版本为 22，低于工程声明的 24。尚无 PR 或 CI，暂不关闭。

## 后续

验证用户现场及真实桌面的刷新／重启场景，完成完整验收和 CI。Node 会话恢复及完整原始档案仍按各自计划处理。关闭条件见 [Bug 跟踪表](bug-plan.md)。
