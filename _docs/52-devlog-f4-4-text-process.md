## 关键决策

- 工具在 tool-started 时记录 startedAt，参数生成 pending 不计执行时间；tool-result 记录 endedAt。命令在第一次 started 记录起点，重复 started 不重置，成功、失败、取消或传输失败冻结终点；缺少起始事件时不虚构耗时。
- 回合失败时仍活动的工具显示失败，其他终态下仍活动的工具显示已取消并冻结计时；已有工具结果不被覆盖。这是前端观察状态，不声称后端产生了额外工具结果。
- 起止时间均为 Renderer 接收事件的本地时间，不是后端精确执行指标；沿用秒级用时格式。没有新增 RPC、取消协议或后端工具，也没有仅定义未落实的契约。
- 原 F4.3 上下两条分割线、底部按钮和折叠思考卡片布局由本记录替代；历史设计文档保留当时决策。
- 新增 Activity 有工具和通知两个消费者，拥有显示计时器与清理；没有新增转发模块。既有 conversation.ts 超过 300 行，本次保留会话状态统一所有者，仅就地增加起止时间与终态收尾，避免为展示改动拆分整套 reducer；其既有测试文件同样保留场景组织。

## 关键决策

```text
Existing content blocks
          |
          v
toolPresentation --> Activity: icon / label / status / toggle
          |                              |
          +------------------------------+
                         |
                    ToolBlock
                         |
               Result-only animated panel
```

- Shell 参数本来就是流式 JSON。shellCommand 仅在 JSON 完整且 command 为非空字符串时展示该字段；不完整时只显示“执行Shell”，不把半截 JSON 当命令，也不展示 timeoutMs 等其他参数。完整命令不在数据层截断，仅由 CSS 按可用宽度省略，悬停可查完整文本。
- 结果使用 detail，缺失时使用 summary，避免把同一输出的摘要和正文重复展示。read/edit/write 按用户要求只展示执行状态，不展开返回内容；错误原因保留。其他工具有 summary/detail/failure 才提供结果按钮。
- Shell 输出是当前后端格式化后的纯文本，参照 `src/tools/builtins/shell/tool.ts` 的 formatShellResult：只将末尾已有的 `[exit code: N]` 移到面板底部，不推断缺失的退出码为 0。工具调用完成与命令退出成功是不同信息，保持后端 status 原义。
- 输出通过 React 文本节点呈现，不执行 HTML。结果折叠后设置 aria-hidden/inert；展开按钮支持键盘，长输出可聚焦滚动。
- 增强高亮使用原演示对照的 #948a7e / #33291f 渐变，在思考、处理状态和工具活动文字上统一启用，终态停止，减少动态效果偏好仍受尊重。
- 每个 SVG 虽小于 40 行，但沿用既有图标目录和统一公共出口，独立维护其图形；tool.ts 负责纯展示规则，有独立场景测试。没有扩展 RPC，没有新增待落实的契约，也未改动已有后端工作。
