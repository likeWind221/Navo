## 关键决策

### 用户确认的交互

- Main 固定存在且不可关闭；点击 Agent 节点打开 Node 入口。切回 Main 清除节点选择；关闭当前 Node 回到 Main 并清除选择，但不清除该 Node 草稿与当前运行期间的预览对话。
- 收起保留会话、面板尺寸与地图位置。完全展开只覆盖地图，不改变地图几何或底层视角；未覆盖区域仍可操作。
- Roadmap 没有滚动条。按住左键移动超过 5px 后进入平移、捕获指针并显示抓取状态；节点与网格同步移动；拖动结束不误触发节点点击，普通点击仍可打开 Node。
- “回到工作节点”立即居中示例中进行中的节点：面板普通展开时使用未被覆盖的区域，收起时使用整个地图。复位不切换会话、不改变选择。示例标记移到左下角，避免与右上角会话恢复按钮重叠。
- 草稿归工作区组件，以 Main/Node ID 分开保存。全局项目切换时组件保持挂载，草稿不丢失；关闭全局项目标签会卸载组件，项目关闭后的状态保留留给 F5.4 实施。

### 当前生产边界

本 Step 是布局与交互设计，不提前实施 F5.4–F5.7：正式入口消费现有项目详情，但不发送 Main/Node 回合、不订阅状态、不绘制真实路线、不确认或跳过节点、不查询消息资源。已有 Roadmap 返回时明确显示“路线已创建”，不把它伪装成空路线或示例进度。复位按钮在没有展示节点时禁用。

真实 Main 对话、目标确认与状态跟随交由 F5.4；真实 Roadmap 的节点、依赖与最新工作节点定位交由 F5.5；Node 执行、控制节点详情和人工控制交由 F5.6；消息资源查询交由 F5.7。运行中离开不取消回合，运行中关闭仅关闭视图，显式停止独立操作；本 Step 只确认交互原则，真实回合与取消机制接入时仍须核对 Harness 和公共协议。

### 模块与函数导读

- `Detail.tsx`：保留异步详情读取、加载/失败和陈旧响应丢弃；`ProjectDetailView` 就绪后按 projectId 挂载 `ProjectWorkspace`，不同项目不会共用草稿状态。
- `Workspace.tsx`：输入为公共 `ProjectDetailV1` 和仅预览使用的可选节点数据；管理活动会话、打开的 Node、浮层尺寸/可见性、草稿与地图位移。`openNode` 打开或激活入口；`closeNode` 关闭入口并在必要时回 Main；模拟发送只在预览入口启用，正式入口发送禁用。

- `preview/Project.tsx`：负责示例项目与节点输入，开发模式懒加载；正式项目入口没有示例数据。
- `View.spec.tsx`：在原项目事实与失败场景上补充正式布局、发送禁用、无示例生成，以及已有路线/活动回合不被伪装的断言。

## 2026-10-26：六边形浮空岛与自适应生成

### 做了什么

用户在三维沙盘基础上进一步授权：参照浮空岛图片，让一个节点对应一座岛，每座岛由六边形块拼成，岛屿随 Roadmap 增删自适应变化。本轮只修改地图、现有快照的显示和开发预览；保留前一节全局视觉样式，不新增后端接口、订阅、Node 执行或人工操作。

- 替换整块大陆为独立浮空岛：六边形草地/池塘/岩石台面、分层岩柱、树木、草丛和云团都是真实三维几何。
- 岛形由节点 ID 的稳定种子生成；当前运行期间按 ID 保留原岛位置与地形，新增节点优先放到已有依赖岛附近的空槽，移除节点只移除对应岛屿和航线。没有布局持久化协议，重开项目会重新生成初始布局；同 ID 的地形仍保持一致。
- 连线读取实际输入的 from/to 边，替换写死的五节点连接；以空中曲线和箭头表达方向。新增/删除岛屿时适配取景，保留当前旋转方向；另提供「适应全部岛屿」。
- 正式项目只读取已返回的公共 Roadmap 快照绘制节点/边，不再伪造空图或示例进度；不新增实时 follow，因此后端后续变化仍需要未来正式接入才能送达组件。预览提供新增、移除控件，全部只改本地示例数据。
- 当前节点删除后回 Main、关闭失效入口，保留已有草稿。清空地图后显示空态，重新添加即可恢复岛屿。

### 关键决策与代码导读

1. `map/model.ts` 只处理图数据和生成规则，不依赖 Three.js。MapGraph 区分节点与有向边；IslandModel 记录所属节点、种子、轴向槽位、六边形地块与世界位置。layoutIslands 先保留仍在图中的 ID，再给新 ID 分配空槽；不做全图重排。岛内始终保留连通的中心地块，外圈按种子变化；节点改名或状态变化不会重生成地形。
2. `map/island.ts` 创建一座岛的几何、云团与中心圈点。每个地块使用六边形柱体和台面，通过实例化绘制；每座岛独立拥有资源，删除时能够单独释放。setState 只更新圈点材质与选中效果。
3. `map/vegetation.ts` 按地块和同一节点种子布置树/草，避开中心圈点。删除旧 `terrain.ts` 以及旧的全大陆高度函数，所有生产引用已迁移。
4. `map/route.ts` 根据输入依赖和当前岛中心创建有向航线。文件虽仅 26 行，保留独立职责：航线随边整体更新，岛屿则按 ID 长期保留；两者生命周期不同，避免混入 Renderer/相机状态。
5. `map/scene.ts` 在 update 中差量增删岛屿，已有实例继续复用；移除时释放实例缓冲、几何和材质。fit 根据实际模型边界及当前视角计算取景，光照范围随群岛扩展；标签投影、遮挡、缩放、平移和相机仍归同一所有者。无空闲渲染循环。
6. `Map.tsx` 挂载时只创建一次 Renderer；数据更新调用 update，选择更新调用 select。latest ref 保证异步加载后使用最新输入，卸载释放场景。增删和清空后恢复都不会重建 Canvas。
7. `Workspace.tsx` 把公共 NodeV1 状态映射为显示状态，completing 对应已完成，submitted 对应待验收；只读取现有事实，不推断执行结果。删去活动节点后回 Main，草稿不丢弃。类型只约束编译期，公共数据的运行时校验仍由已有 RPC 边界负责。
8. `preview/Project.tsx` 默认直接展示群岛，并提供新增/移除。开发预览与离线 HTML 共用生产组件，没有模型或后端调用。

```text
  -> Model: stable seeded hex islands + free slots
  -> Scene.update: retain / add / remove islands
  -> Island geometry + directed dependency routes
  -> Existing camera controls + clickable Node labels
```
