# BUG-048：Node 未提交时错误展示验收卡片

## 现象与复现

2026-11-17 用户截图显示 Node 回合结束后待复盘、没有提交作业，“退回修改”按钮禁用。用户还要求将验收内容作为对话中的独立交互卡片，并为 Main 和 Node 开放完整文件系统工具。

## 已证实事实与根因假设

`ProjectRuntime.nodeActions` 仅在 Node 为 submitted 时开放人工 rework，`NodeStore.requestRework` 也只接受 submitted。截图中的未提交与按钮禁用符合此限制，但未读取用户现场状态。Main 与 Node 的各自工具清单仅按能力条件加入 read；Host 已注册 read、write、edit 和 shell 等通用文件工具。

## 修复内容

前端将验收面板移到消息列表末尾，以独立卡片展示，并说明 idle 且无作业时不能退回、可在对话中直接提出修改要求。未修改后端；未提交节点能否直接退回及 Main / Node 完整文件工具开放交接后端。

2026-11-17 用户纠正：应仅在 LLM 使用提交工具交作业后显示验收卡片；不要求未提交状态开放退回。已撤回上述原因提示，并将卡片显示条件收紧为 Node 状态为 submitted 且有作业数据；普通回合结束、reviewPending 或历史反馈不再单独触发卡片。Main / Node 完整文件工具仍是另一个未完成的后端交接事项。

## 验证结果与边界

前端定向测试 2 文件、19 项通过，类型检查通过；测试覆盖验收卡片在助手回复之后、普通回合和未提交状态不显示、成功提交后显示。未完成真实 Electron 人工验收，未复现或修改用户现场节点；未验证后端退回行为或文件工具真实调用。本机 Node 22 低于工程声明的 24。

## 后续

复验普通回合不显示卡片、提交工具成功后显示卡片及其验收操作，并完成真实桌面与 CI。另行交接 Main / Node 完整文件系统工具；关闭条件见 [Bug 跟踪表](bug-plan.md)。
