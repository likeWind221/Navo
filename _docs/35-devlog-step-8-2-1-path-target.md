# 8.2.1 工作区定位与文件目标

## 做了什么

- 新增文件执行工作区与文件目标解析能力。
- 固定并规范化宿主提供的绝对 `cwd`，要求其为现存目录。
- 相对路径以 `cwd` 为基准，绝对路径保留执行世界语义；现存路径解析为真实路径，缺失叶子使用规范化父目录和叶子名形成目标。
- 增加共享 `cwd`、不同 `cwd`、`.`/`..`、符号链接、缺失目标和错误分类测试。

## 关键决策

- 对齐 DSH 的 `SessionHeader.cwd` 与 FS target 思路，不使用 `sessionId` 创建物理目录，也不把路径解析伪装成沙箱授权。
- `FileTarget.path` 是后续读写使用的稳定本机绝对路径；`exists` 区分现存目标和可供后续创建的缺失叶子。
- 现存符号链接沿真实目标归一化；缺失目标只归一化已存在的父目录，父目录缺失直接返回 `not-found`。

## 坑与发现

- 当前子步骤只提供路径目标 helper，尚未把 `read/find/write/edit` 接入 `ToolService`，也未执行文件内容 IO。
- `cwd` 的具体 Session 创建入口和沙箱/权限策略仍属于宿主后续接入范围；绝对路径不因本步骤被限制在 `cwd` 内。
