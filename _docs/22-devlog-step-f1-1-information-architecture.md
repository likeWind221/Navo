# Step F1.1 页面信息架构开发记录

## 做了什么

- 定义目标首页、目标工作区、Node 学习工作区和设置页的层级与职责。
- 明确 Node 工作区中的教材、练习和统一对话布局，以及加载、失败、取消和恢复状态。
- 记录学习者视图、Session 隔离、隐藏答案和未来 preload 接口的权限边界。

## 关键决策

- Node 学习工作区是首个实际实现页面；Main Agent 与 DAG 页面只保留未来位置，不伪装为当前可用功能。
- 教材与练习是同一 Node 下的领域面板，统一对话使用单一 NodeSession，响应式布局不改变领域身份。
- 前端保留草稿和请求状态，但领域事实始终以后端确认的快照为准。

## 坑与发现

- “内容已生成”和“Agent 回答完成”都不等于 Node 已掌握，界面必须等待 Verification 事实。
- 隐藏参考答案不能只靠视觉隐藏，未来跨进程契约必须直接提供学习者视图。
- 当前后端尚未提供 Main Agent、DAG 与跨进程接口，因此信息架构不能倒逼虚构接口。

人工审查后进入 F1.2，仅实现 Node 学习工作区静态布局和状态样例。
