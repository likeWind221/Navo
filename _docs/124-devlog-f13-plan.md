# F13 项目资料库与任务检索规划

> 日期：2026-10-18
> 状态：规划记录；F13.0 产品设计已完成；F13.1a Step C/D 已实施并验收，PR #80 与 BUG-023 修复 PR #81 已合入 master。当前收尾 PR 仅同步文档状态；后续先进行 F13.1b 技术设计。本记录本身不是 F13.0 产品设计交付。

## 做了什么

- 按用户确认，将项目内 Resource 的集合定位为项目资料库：统一组织参考资料与 Agent 成果，通过权限内检索、按需阅读和可核验引用支持长程任务。
- 在 [后端计划](backend-plan.md) 登记 F13.0–F13.6 功能目标，并将 F13.1 拆为 F13.1a 共享资产生命周期内核、F13.1b 正文处理恢复和 F13.1c 用户资料补充与管理接入。
- 在 [前端计划](frontend-plan.md) 登记桌面消费与验收边界；更新 [PRD](00-navo-prd.md) 的旧阶段定义，使 Phase 11 自动推进、Phase 12 上下文压缩、Phase 13 项目资料库与当前计划一致；在 [索引](index.md) 登记本记录。
- 当前 Agent 串行维护上述共享文档；仅授权文档更新与推送，不实施代码、公共契约或真实模型实验。

## 关键决策

- Resource 继续作为资料身份、项目归属与权限的权威来源，资料库提供组织与检索体验；不另建冲突的资料管理体系。Main 可读本项目全部 Resource，Node 沿用既有可见范围；public 仅为项目内共享。
- 参考资料与 Agent 成果明确区分。发布或引用不等于已核实，不能把 Agent 生成内容自动提升为事实依据。
- 首版目标为 Markdown、TXT 和可提取文本的 PDF；资料已保存与可检索分别表达。当前 Resource 按行读取文本，现有 revision 不构成正文多版本管理；用户导入归属、正文变化、停用、删除和历史引用规则由 F13.0 收口。
- 简单分类、标签和筛选优先；RAG 支持查找与有依据的任务执行。算法、Embedding、重排、向量库与供应商均未选定；尚未设计或落实新 API。
- 保留 F12 压缩，跨项目知识库、Session / 压缩历史召回、任意 Workspace 全量检索、外部同步、知识图谱与复杂扫描件理解后移。

- 本次仅做文档差异、相对链接与阶段状态一致性检查，不运行无关代码测试。检查不证明任何 RAG 行为或正式 UI 可用。
