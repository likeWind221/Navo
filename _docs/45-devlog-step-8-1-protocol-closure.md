# 8.1 文件工具协议收口记录

## 做了什么

- 将文件工具请求和结果从 `read/find/write/edit` 收口为 `read/write/edit`。
- 移除文件工具层的 `find` Schema、扫描专用限制和相关模型错误文案。
- 保留相对/绝对路径语义和 `sessionId`、工作区根不进入模型参数的约束。

## 关键决策

- 文件发现交给后续 `shell`，`read` 只处理模型已经给出的文件路径。
- 本步骤只收口协议和错误，不执行文件 IO；读取行为由 8.2.2 实现。

## 坑与发现

- 旧协议测试和 `output-too-large` 文案仍隐含独立 `find`，需要一并清理，否则模型面仍会暴露已废弃能力。
