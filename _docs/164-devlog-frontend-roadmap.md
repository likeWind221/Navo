### 文件职责与边界

本轮只新增 / 修改规划文档。后续具体文件清单在各 Step 启动时依据真实源码确定，不提前创建模块；大致职责为：

- `frontend/src/workspace/**`：会话、项目、设置等页面及其展示状态；已有聊天内容和浮空岛地图继续复用。
- `frontend/shared/**` 与 `frontend/electron/{ipc,preload}/**`：受校验的桌面入口、请求身份、取消及窗口生命周期；不能让 Renderer 获得任意 IPC、后端 Store 或原始文件访问。

### 现有能力与新增契约

| 已核对的现有基础 | 后续仍需交付的能力 |
|---|---|
| SessionStore 保留事件并维护有效 surface；现有 history API 是有效历史 | 普通会话目录 / 管理、完整可公开原始历史、回合终态与查询范围；不能前端读库完成 |
| M1 已有可信账号登录 / 登出 / 模型目录，正式 Host 从可信配置装配 Provider | 桌面账号入口、可公开配置、保存 / 生效与忙时互斥；登录成功不证明真实推理可用 |
| ProjectStore 有 archive / reopen，Project RPC 输出 active / archived | 带版本与运行冲突处理的用户操作、归档只读和恢复语义；不能仅改列表标签 |

模型设置先做应用级默认和明确生效范围。令牌继续由可信服务持有，不自动切换账号或 Provider；首版不新增 Renderer 密钥编辑。`/clear` 对普通会话表示新开并保留旧档案，不能清空项目状态；`/model` 必须与设置的真实生效语义一致。

用户已取消正文预览、图谱浏览与独立引用管理，不保留后续实施安排。资料继续通过 F7 的信息、搜索与系统默认应用入口使用；已有后端正文提取、GraphRAG 和工具轨迹不因取消桌面功能而删除，后端 F13.5 的取消决定不变。
