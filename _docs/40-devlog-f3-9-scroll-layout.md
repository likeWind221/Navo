# F3.9：滚动区与输入框布局

## 做了什么

- 将消息历史区改为覆盖顶部栏以下完整聊天视口的独立滚动层，使右侧滚动条延伸至窗口底部。
- 将输入框区域改为贴近底部的覆盖层，移除顶部间距，保留左右和底部间距。
- 为整个输入区域设置不透明画布背景，使滚入输入框及其 padding 区域的消息不再透出。
- 将助手消息的横向占位扩展至消息列全宽，使左右边界与输入框一致；用户消息仍按内容宽度靠右显示。
- 在消息列统一增加左右内边距，输入框尺寸不变；助手消息相对输入框等量缩进，用户消息右边界使用同一缩进。
- 为消息列预留输入框高度，保证末条消息能够滚动到输入框上方，不被覆盖。
- 扩展 Electron 桌面 QA，检查助手消息相对输入框的左右缩进对称、用户消息采用相同右侧缩进，以及滚动区和输入区域边界。

## 关键决策

- 滚动所有权继续属于消息历史区；输入框仅改变布局层级，不改变提交、停止或会话状态逻辑。
- 保留对称滚动条槽位，避免 F3.8 已修复的消息列水平偏移再次出现。
- 桌面与窄窗口分别设置底部预留空间，以匹配各自输入框高度和底部间距。

## 坑与发现

- 原布局中消息历史区与输入框是纵向 Flex 兄弟节点，因此滚动容器物理上只能延伸到输入框顶部。
- 输入框区域原有顶部 padding，造成消息区和输入框之间仍存在额外间距。
