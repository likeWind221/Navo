# F1.2 三版 Node 视觉原型（进行中）

## 做了什么

- 实现 A 探险手册、B 战术指挥台、C 山丘远征站，可通过页面顶部按钮切换。
- 使用亮白背景、自绘六边形森林/平原/山丘插画和同一组教材、练习、统一对话演示内容。
- 增加 `pnpm --dir frontend dev:web`，浏览器不依赖 Electron preload 即可查看。

## 关键决策

- 三版分别采用侧栏阅读引导、横向任务条和远征卡片，不仅替换颜色。
- 六边形地块目前只是节点概念插画，不实现 DAG、地图导航或游戏进度。
- 所有内容明确标注演示；发送禁用，输入仅草稿，隐藏答案不进入页面。
- 原型独立放在 `prototype/`，待用户选定后再按组件职责收敛，不作为完整 F1.2 验收。

## 坑与发现

- Electron 二进制不可用不应阻塞视觉评审，因此独立提供浏览器预览入口。
- 已通过前端 typecheck、生产 build，以及预览入口 HTTP 200 检查；尚未进行浏览器截图和人工视觉验收。
- 宽屏显示内容与对话分栏，窄屏纵向排列；真实导航、空态和错误态的完整验收仍未实现。
- 浏览器白屏排查：独立 Vite 未加载 Electron 配置中的 React 插件，错误生成依赖全局 React 的 JSX。新增 `frontend/vite.config.ts` 并纳入类型检查；重新启动预览后确认 main 与 Terrain 返回自动 JSX runtime 导入，typecheck、浏览器构建和 Electron 构建通过。HTTP 200 不等于页面成功渲染，仍需人工浏览器检查。

## 下一步

用户查看三版并选择方向，再细化选中方案；F1.2 保持进行中。
