# BUG-049：Node 对话记录不显示

## 现象与复现

2026-11-17 用户报告 Node 记录再次变空，并提供对话区域空白截图；尚未读取现场会话或独立复现。

## 已证实事实与根因假设

`ProjectConversation` 仅为 Main 加载历史；Node 消息由 `ProjectTurns` 保存在前端进程内存。前端刷新或重启会丢失这部分内存，但本次具体触发操作尚未核实。后端已注册 `project.session.recovery.v1`，可返回 Node 会话 ID、是否可用及上次结束状态，桌面 Project Bridge 尚未接入该方法；已有 Session Bridge 可按已知 ID 查询有效历史。现场记录是否仍存在尚未核验。

## 修复内容

已接入项目会话恢复 RPC 的桌面 Bridge，按 projectId 和 nodeId 查找会话；可用时通过已有 Session Bridge 分页读取有效历史，未建立会话时提示，无法读取时显示错误及重试。历史加载完成前禁用输入；首次读取结果在当前前端运行期间缓存，切换视图时与运行期新消息衔接。此前 BUG-047 修复只覆盖 Main。

## 验证结果与边界

前端定向测试 3 文件、17 项通过；完整前端测试 34 文件、209 项通过，类型检查和构建通过。覆盖指定节点定位、分页、缓存、无会话、不可读及桌面桥校验；未验证真实现场历史、Electron 刷新 / 重启以及中断回合的状态展示。用户表示自行进行桌面验收。接口提供有效历史，不保证压缩前的完整原始记录。本机 Node 22 低于工程声明的 24；无当前 head CI。

## 后续

由用户完成真实刷新／重启和现场验收；中断状态展示、普通会话历史及完整 CI 按 F6 计划继续。按 [Bug 跟踪表](bug-plan.md) 的关闭条件处理。
