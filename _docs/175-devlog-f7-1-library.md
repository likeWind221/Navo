# F7.1 项目资料库浏览与信息

## 做了什么

- 正式 Project 工作区增加资料库入口，用户可浏览根目录及子目录、返回上级、通过路径导航定位，并选择资料查看名称、描述、创建者、版本和正文处理状态。
- 每个已打开项目持有自己的目录与选中状态；资料变化后跟随更新，所选资料被删除时清空信息。关闭资料库释放观察；隐藏项目保留自身状态，Escape 只关闭当前可见项目的资料库。
- 保持现有配色、卡片、边框与字体；宽屏资料和信息并排，窄屏改为纵向滚动。未接入导入、编辑、搜索、正文预览或图谱浏览。

## 关键决策

- App 显式传入 Resource API，Workspace 只管理入口与开关；`resource/hook.ts` 拥有目录、选中项、订阅及清理，`Library.tsx` 负责界面，`model.ts` 与 `failure.ts` 负责公开状态文案。
- 先监听再请求 follow，确认返回订阅身份后只重放该身份的最新快照和终态错误；目录/项目变化与卸载后，迟到确认也会被取消。失败保留到用户显式重试，不增加轮询或自动重试。
- 正文 ready 仅显示“正文就绪”，不宣称检索就绪；正文为空显示“尚未处理”，仅 metadata_only 显示“仅元数据”。

## 坑与发现

- 窗口切换不等于卸载隐藏项目；关闭键监听必须跳过 inert 的隐藏区域，避免误关闭另一个项目。
- 正式 QA 首轮使用带点的 requestId 被接口拒绝；后续曾等待已经发出的页面加载事件，以及在打开 B 项目前等待其页面。这些均为 QA 代码错误，按原因修正，保留各轮失败现场，未增加生产重试或放宽验收。
- QA 调用真实 IPC 取消并记录结果，不要求 follow 发出只有 import 才提供的完成事件；主进程关闭仍走正常 Host 清理。
