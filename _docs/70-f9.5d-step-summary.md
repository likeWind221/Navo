# F9.5d Step Summary

`modify_roadmap` is the Main-Agent-only mutation boundary for an existing Project Roadmap.

```text
read_roadmap -> exact base_version
      |
      +-- read_node -> exact node_version (edit_node)
      v
modify_roadmap(one action)
      v
trusted Main Binding
      v
RoadmapStore.change
      +-- prepare Node changes
      +-- validate stale revisions
      +-- rebuild DAG
      +-- reject invalid working-node consequences
      v
atomic Node + Roadmap commit
      v
new authoritative Roadmap version
```

Supported planning actions are add_node, edit_node, connect, disconnect, reorder and remove_node. Node completion and skip remain outside Main Agent authority because they require the existing human confirmation boundary.
