# F3.4 助手内容展示

## 做了什么

- Renderer 的助手消息改为按 `blocks` 顺序展示 `text`、`reasoning` 和 `tool-call`。
- reasoning 使用默认折叠的 `details`，工具卡片展示工具名、参数、结果摘要/详情及执行状态。
- 保留 v1 聚合文本渲染兼容路径，并增加三类内容顺序、工具失败与取消状态的展示测试。

## 关键决策

- `tool-result` 更新对应的 `tool-call` 卡片，不另建兄弟卡片，保持调用与结果的关联。
- 参数和结果默认折叠，长文本使用换行与内部滚动，避免撑破窄窗口。
- React 负责纯文本转义，不引入 Markdown 或 HTML 解释器。

## 坑与发现

- 旧版 v1 消息没有 `blocks`，必须继续从 `message.text` 渲染；v2 即使没有正文也要保留空的 block 容器以呈现等待或终态。
- `reasoning -> tool-call -> text` 的顺序由数组顺序保留，不能重新使用聚合正文替代内容块。
